
# AutoDock Vina Docking Pipeline

Configurable small-molecule docking pipeline, demonstrated on inhibitors of acetylcholinesterase (AChE), a primary drug target in Alzheimer's disease.

This pipeline prepares a protein receptor and a set of small-molecule ligands, computes a docking box around the target's active site, and runs [AutoDock Vina](https://vina.scripps.edu/) to estimate binding affinities. AChE (UniProt P22303, isoform P22303-2) is used as a worked example, but the pipeline generalises to other targets by changing the receptor structure and the active-site residues used to place the box.

## Pipeline overview

Four scripts, run in order. Each produces the input the next one needs.

1. `receptor_prep.py` — cleans raw receptor PDB files and converts them to PDBQT (via Meeko).
2. `ligand_prep.py` — reads a CSV of ligand names + SMILES, generates 3D conformers (RDKit), and writes ligand PDBQTs.
3. `box_centre_locator.py` — computes the docking box centre from the catalytic-triad Cα coordinates.
4. `vina_run.py` — docks each ligand against the receptor with AutoDock Vina.

Receptor prep and ligand prep are independent, so their order relative to each other doesn't matter — but both must be done before docking.

## Receptor

The receptor is an AlphaFold-predicted model of human acetylcholinesterase (UniProt isoform P22303-2, the full-length isoform), generated by T. Dahl. Note that this isoform carries a +31 residue-numbering offset relative to the canonical mature sequence, so the catalytic-triad residues used to place the docking box are numbered accordingly (Ser234 / Glu365 / His478).

## Requirements

All dependencies are captured in `environment.yml` (Python 3.10, RDKit, Meeko, AutoDock Vina, pandas). Recreate the environment with conda/miniforge:

```bash
conda env create -f environment.yml
conda activate docking
```

Run all scripts from the project root (the folder containing the scripts), so the relative folder paths resolve correctly.

## Usage

### 1. Prepare the receptor

Create a folder called `uncleaned_receptors/` and place your raw receptor PDB file(s) in it. (If the folder doesn't exist, `receptor_prep.py` creates it, tells you to add your files, and exits — just re-run after.)

```bash
python receptor_prep.py
```

Each PDB is stripped to `ATOM`/`TER` records (written to `cleaned_receptors/`), then converted to a PDBQT in `preped_receptors/`. Receptors that already have a PDBQT are skipped.

### 2. Prepare the ligands

Put a CSV with two columns — `name` and `smiles` — in the project root (see `ligands.csv` for the template). Then:

```bash
python ligand_prep.py
```

Each ligand is embedded in 3D and written to `preped_ligands/` as `<name>.pdbqt`. Ligands that already have a PDBQT are skipped.

> Use isomeric SMILES (with stereochemistry) for chiral molecules — flat SMILES cause 3D embedding to fail.

### 3. Find the docking box centre

`box_centre_locator.py` averages the Cα coordinates of the catalytic-triad residues to get the box centre.

Before running, edit the two values at the top of the script for your target:
- `residue_filter` — the three catalytic residues, written **exactly** as they appear in your PDB file (mind the column spacing — PDB right-justifies residue numbers).
- the receptor path in the `open(...)` call — points at the raw PDB in `uncleaned_receptors/`.

```bash
python box_centre_locator.py
```

It prints the box centre as `(x, y, z)`. Note the numbers — you'll paste them into the next step.

### 4. Run the docking

`vina_run.py` docks every ligand in `preped_ligands/` against the receptor in `preped_receptors/`. Before running, edit these values in the script for your target:
- `receptor_path` — the receptor PDBQT filename.
- the box centre (`--center_x/y/z`) — paste the numbers from step 3.
- the box size (`--size_x/y/z`) — default is a 25 Å cube.

```bash
python vina_run.py
```

Results are written to:
- `output/logs/` — Vina's full log per ligand (contains the binding-affinity table).
- `output/pdbqts/` — the docked pose for each ligand.

## Adapting to a new target

The receptor prep, ligand prep, and docking steps are target-agnostic. To dock against a different protein, supply target knowledge in two places:
- the active-site residues used to place the box (`box_centre_locator.py`)
- the receptor filename and box parameters (`vina_run.py`)

Everything else runs unchanged.
